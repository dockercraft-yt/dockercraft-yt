## Servus, ich bin Stefan.

Fachinformatiker für Systemintegration. Auf **DockerCraft** zeige ich, wie du Container vom ersten `docker run` bis zum eigenen Homelab aufsetzt. Mit Unraid, Home Assistant und allem dazwischen. Hier liegt der Code zu den Videos.

### Woran ich gerade baue

Zentrales Logging mit Grafana Alloy, Loki und Grafana.<br>
Home-Assistant-Add-ons und Sensoren für den Alltag.

### Stack

Docker · Docker Compose · Unraid · Home Assistant · Grafana · Loki · Bash · PowerShell · SQL Server

### Projekte

**[ha-addon-alloy](https://github.com/dockercraft-yt/ha-addon-alloy)**<br>
Grafana Alloy als Add-on für Home Assistant OS. Schickt HA-, Supervisor- und Add-on-Logs an Loki.

**[Tiptoi-Media-Downloader](https://github.com/dockercraft-yt/Tiptoi-Media-Downloader)**<br>
Self-hosted Katalog öffentlich erreichbarer tiptoi-Audiolinks. Titel, Thumbnails und .gme-URLs in SQLite.
